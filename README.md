# Tevt-TV Online

This is a side project I made after learning the basics of node.js. We had a group project, but I wanted to test myself and make a project on my own aswell.

## Architecture decisions

Since the project consists of only a few pages, the header markup is repeated
manually in each HTML file. For a project of this size, simplicity was
prioritized over DRY — if the project were to grow, a template engine
like EJS would be a natural next step.
